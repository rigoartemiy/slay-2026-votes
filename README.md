# Рейтинг голосований SLAY AWARDS 2026

Сайт показывает общий зачёт стримеров, топы всех 16 номинаций и ленту открытых бюллетеней.

**Сайт:** https://rigoartemiy.github.io/slay-2026-votes/

## Возможности

- Общий зачёт суммирует голоса за стримеров в персональных номинациях.
- Каждая номинация открывается отдельной кнопкой сверху.
- В ленте бюллетени расположены от новых к старым. Нажми на карточку, чтобы увидеть выборы автора по всем номинациям.
- При ничьей участникам показывается общее место со знаком «=»; следующий ранг учитывает число участников на равном месте.
- У каждого кандидата есть раскрывающаяся кнопка «Кто голосовал». В списке указаны авторы открытых бюллетеней и даты публикаций.
- 5opka, XAH0B и Cacto0o выделены оранжевым градиентом. Трек «ТУСА МЕДУЗА» и пара «5opka & Sonasheka» отмечены отдельно.
- Основная палитра сайта — чёрно-оранжевая; на фоне повторяется надпись SWINLINE.

## Данные и обновление

GitHub Actions проверяет открытый канал Telegram [@slay_awards](https://t.me/s/slay_awards) каждые 15 минут, обновляет файл data.json и публикует сайт. Открытая страница запрашивает свежие данные каждые 5 минут.

Автор и дата бюллетеня берутся из открытой публикации Telegram. Если имя автора не удалось определить, в ленте отображается «Автор не указан».

## Публикация

В настройках репозитория выбери **Settings → Pages → GitHub Actions** в качестве источника публикации. Файл .github/workflows/update-pages.yml запускает сбор данных и выкладку сайта.
